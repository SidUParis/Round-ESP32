# Round Companion — 圆屏伴侣原型 02

可点击的浏览器原型，固定 466×466 逻辑画布，随窗口等比缩放。当前未烧录到 ESP32；没有连接真实手机、控制音乐、访问麦克风或读取任何账号数据。

## 打开

本次已启动临时用户后台服务 `round-esp32-preview.service`，只监听 127.0.0.1，不开机自启。

- 浏览器地址：http://127.0.0.1:8765/
- 停止：`systemctl --user stop round-esp32-preview`
- 若服务未运行，从本目录执行 `python3 -m http.server 8765 --bind 127.0.0.1`。

服务根目录是 `ui-preview`，不提供上级目录中的硬件备份。

## 本轮变更

- 删除绘画入口及交互代码。
- AI 直接在桌面开始、取消并呈现聆听/思考/回应，无独立 AI 页面。屏幕中间的图形、时钟及顶部状态区连续变化。
- 顶部改成动态状态区，可展开查看 BLE / Wi-Fi 和连接对象。短暂操作反馈也进入同一个状态区。
- 音乐改为手机遥控的演示。播放/暂停、切歌与环形声波可交互。没有连接手机的场景禁用遥控。
- 随声动效单独开关，模拟本地麦克风感知，和 BLE 播放状态独立；本原型没有调用麦克风。
- 连接场景可选择未连接、手机、电脑。均为本地模拟，不进行蓝牙配对或 Wi-Fi 配置。
- 电脑看板包含 Codex / Claude Code 的未接入、示例数据和断连后过期状态。示例 68% / 42% 均为硬编码布局数据，不是用户额度。
- 保留重力球、频谱、设置和视频占位入口。
- 两个可点击侧键：键 1 在应用中返回桌面、空闲桌面息屏、息屏时唤醒；键 2 在桌面开始/结束模拟对话、在音乐页模拟播放/暂停，在其他页直接回桌面对话。
- 两种配色、动效开关和自动导览；遵循减少动画设置。

按键位置是原型示意，尚未按实物外壳测量。真实 PWR 长按及 BOOT 启动语义不在浏览器原型中更改。

## 技术边界

真实固件计划沿用 ESP-IDF / FreeRTOS / LVGL。本原型的 CSS 材质、SVG 动效不能原样运行于 ESP32。移植时将使用弧线、位置/透明度动画或有限尺寸预绘制素材，并实测内存及帧时间。

参考和接入计划见上级 `COMPANION-DESIGN.md`。当前的全部真实原系统 Flash 仍保存在受限权限的 `backups` 目录。

## 本轮验证

2026-09-15 已在浏览器检查：桌面对话保持 `view-home`；顶部状态区展开到 188 px；按键一返回/息屏、按键二播放/暂停；切歌；电脑额度空值、加载示例、断连过期；断连时媒体遥控禁用而声音动效仍可独立运行；关闭 Wi-Fi 后桌面 AI 保持空闲并显示联网提示；390×844 窄屏保持圆形且无水平溢出；减少动画开关有效。JS 语法检查通过，浏览器未发现应用运行错误。

这些验证仅覆盖浏览器原型；无线协议、真实额度来源、硬件按键、麦克风和帧率均未进行本轮上板验证。
